## 🔧 Troubleshooting Common Issues

**Problem: App won't start**
- Close other heavy programs
- Make sure your Windows is updated
- Try running as administrator (right-click > Run as administrator)

**Problem: No clips generate**
- Check your video file – make sure it opens in a normal player
- Try a shorter video first
- Reduce the number of clips requested

**Problem: Captions look wrong**
- Check your video has clear speech
- Try a different caption style
- Make sure no background music overpowers voices
